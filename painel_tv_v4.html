Escolha como conectar o painel à planilha de respostas do Forms — sem precisar do Azure AD.

🤖 Power Automate
🔗 JSON Direto
🗂️ Colunas
⏱️ Intervalo
💡 Como funciona O Power Automate lê o Excel do Forms de 5 em 5 minutos e salva um arquivo JSON no SharePoint. Você compartilha esse arquivo e cola o link aqui. O painel atualiza automaticamente, sem Azure AD!

Passo a passo — Power Automate

1
Acesse make.powerautomate.com → clique em + Criar → Fluxo de nuvem agendado
2
Configure a recorrência: a cada 5 minutos (ou o intervalo que preferir)
3
Adicione a ação Excel Online (Business) → Listar linhas presentes em uma tabela
Selecione o arquivo de respostas do Forms no OneDrive/SharePoint
4
Adicione Variáveis → Inicializar variável:
Nome: jsonDados · Tipo: String · Valor: [
5
Adicione Aplicar a cada um sobre o resultado da tabela Excel.
Dentro do loop, adicione Acrescentar à variável de cadeia de caracteres:
Cole o modelo JSON abaixo (clique para copiar):
{"nome":"@{items('Apply_to_each')?['NomeDoFiscal']}","status":"@{items('Apply_to_each')?['Status']}","justificativa":"@{items('Apply_to_each')?['Justificativa']}"},
📋 clique para copiar
⚠️ Troque NomeDoFiscal, Status e Justificativa pelos nomes exatos das colunas da sua planilha.
6
Após o loop: Compor → junte: concat('[', trim(variables('jsonDados'), ','), ']')
7
SharePoint → Criar arquivo:
Nome: dados_painel.json · Conteúdo: saída do Compor
8
No SharePoint, abra o arquivo dados_painel.json → clique nos 3 pontos → Compartilhar → Qualquer pessoa com o link pode visualizar → copie o link direto de download
9
Cole o link na aba 🔗 JSON Direto ao lado e clique em Salvar ✓
📋 Cole aqui o link do arquivo JSON gerado pelo Power Automate O arquivo deve ser compartilhado publicamente no SharePoint/OneDrive.
Formato esperado: array JSON com objetos contendo os campos da planilha.
URL do JSONBin: https://api.jsonbin.io/v3/b/SEU_BIN_ID/latest
Em jsonbin.io → API Keys → copie a Master Key
Dados de teste — usados somente se a URL estiver vazia. Útil para verificar se as colunas estão corretas.
🗂️ Mapeamento de colunas Informe o nome exato das colunas no JSON (= cabeçalho da planilha do Forms). Se deixar em branco, o painel tenta detectar automaticamente.
Valores: OK = correto · texto com DIV = divergência
Recomendado: igual ao intervalo do fluxo Power Automate
